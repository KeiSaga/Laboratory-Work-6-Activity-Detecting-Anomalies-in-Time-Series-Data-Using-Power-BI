# IS107 Laboratory Work 6 - Detecting Anomalies

## Overview

This project demonstrates anomaly detection in time-series data using
Power BI.

## Expected Outputs

-   Line chart with anomalies
-   Anomalies explanation pane
-   Short analysis

## Steps Performed

1.  Imported dataset into Power BI
2.  Created a line chart (Period vs Tourists)
3.  Enabled anomaly detection
4.  Used 'Explain By' with Accommodation Type and Travel
5.  Analyzed detected anomalies

## Analysis

The dataset shows a clear seasonal trend in tourist arrivals, with
recurring peaks during certain months. Anomalies were detected where
values significantly deviated from expected patterns. High anomalies
indicate unusually large tourist counts, while low anomalies reflect
sudden drops. Some anomalies are obvious, such as sharp declines likely
caused by external disruptions. Others are subtle and require deeper
inspection of contributing factors like travel type or accommodation.
The explanation pane suggests that international travel significantly
influenced certain anomalies. However, AI-generated explanations should
be validated with real-world context. Overall, anomaly detection helps
quickly identify unusual patterns for further investigation.
